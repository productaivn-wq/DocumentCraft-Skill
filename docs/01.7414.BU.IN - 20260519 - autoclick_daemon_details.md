# AutoClick

Companion to the `git-buster/antigravity-auto-accept` VS Code extension.
That extension only clicks buttons in the **active** Agent Manager tab.
This daemon covers **every open conversation** automatically — without
stealing focus or switching tabs.

---

## 🎯 What It Does

| Feature | Detail |
|---|---|
| Full-DOM sweep | Scans **all** conversation panels (active + hidden) in one `querySelectorAll` — zero tab switching |
| Zero focus steal | Uses browser-level CDP websocket with `Target.attachToTarget(flatten)` — never activates the Electron window |
| CDP auto-detect | Reads port from `DevToolsActivePort` → `argv.json` fallback — no manual `--port` needed |
| Pre-flight check | Verifies CDP is reachable before entering main loop |
| Singleton guard | PID file prevents duplicate daemons |
| Exponential backoff | Retries with backoff; exits after 10 consecutive failures |
| File logging | Always writes to `autoclick.log`, even under `pythonw` |
| Safety blacklist | Never clicks if context contains dangerous patterns |
| Dry-run mode | Log-only mode for safe testing |
| No Playwright | Pure `websocket-client` + HTTP — no browser automation framework needed |

---

## Architecture (v3)

```
Browser-level WebSocket (/json/version → webSocketDebuggerUrl)
    │
    ├── Target.attachToTarget(flatten=true)  ← no window activation
    │       └── Runtime.evaluate(scan JS)    ← scans entire DOM
    │
    └── HTTP /json/list → find Manager page by title/URL
```

All conversation panels share one DOM. A single `querySelectorAll('button, [role="button"]')`
finds approval buttons in **active and hidden panels** — no tab switching needed.

## 🚀 Usage

### Start daemon (background)
```powershell
.\scripts\run_autoclick.ps1
```

### Start daemon (foreground, with logs visible)
```powershell
python "D:/WORK/antigravity/antigravity/skills/AutoClick/scripts/multi_session_autoclick.py"
```

### Dry-run (no actual clicks — just logs what it would do)
```powershell
python .\scripts\multi_session_autoclick.py --dry-run
```

### Stop daemon
```powershell
Get-Process pythonw | Stop-Process
```

### Tail the log
```powershell
Get-Content "D:/WORK/antigravity/antigravity/skills/AutoClick/scripts/autoclick.log" -Wait
```

## ⚙️ Configuration

CDP port detection priority: `DevToolsActivePort` → `argv.json` → default 9333. CLI flags override:

| Flag | Default | Description |
|---|---|---|
| `--port` | Auto-detected | CDP remote debugging port |
| `--interval` | `2.0` | Seconds between full DOM sweeps |
| `--dry-run` | off | Log buttons without clicking |
| `--verbose` | off | Enable debug-level logging |
| `--stale-timeout` | `300` | Seconds before a stuck tab is stopped+retried |
| `--max-retries` | `10` | Consecutive connection errors before exit |

---

## ⚠️ Prerequisites

- Antigravity launched with CDP (port 9333 set in `argv.json`)
- `websocket-client` Python package: `pip install websocket-client`
